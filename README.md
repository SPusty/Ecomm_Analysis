# ecommerce-analysis

## Objective

This project implements a data pipeline for ingesting, validating, and analysing e-commerce sales data using Python and MySQL.
The SQL analysis performs data inspection, duplicate detection, sales aggregation, customer analysis, product ranking, and daily sales trend analysis.

## Tools Used

- Python
- SQL
- GitHub
- Visual Studio Code
- MySQLWorkbench

## Project Phases
1. Python based ETL pipeline to read the source CSV, perform validations and load it into the SQL table.
2. Data inspection and quality check using SQL
3. Total sales and Unique Customer distribution by Country
4. Sales trend analysis by comparing daily sales then calculates percentage changes.

## Important notes

- Used synthetic data for this project.
