# Ecommerce Sale Data Analysis

## Objective

This project implements a data pipeline for validating, ingesting data using Python and analysing e-commerce sales data using MySQL.
The SQL analysis performs data inspection, duplicate detection, sales aggregation, customer distribution, product ranking, and daily sales trend analysis.

## Tools & Technologies

- Python
- SQL
- GitHub

## Project Phases
1. Python based ETL pipeline to read the source CSV, perform validations and load it into the SQL table
2. Data inspection and quality check using SQL
3. Total sales and Unique Customer distribution by Country
4. Sales trend analysis by comparing daily sales then calculates percentage changes

## Important notes

- Used synthetic data for this project.
